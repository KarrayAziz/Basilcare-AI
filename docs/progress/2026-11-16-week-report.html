1. BasilCare in one picture

BasilCare watches a small hydroponic basil farm, where the plants grow in water with nutrients instead of soil. Small sensors measure the water and the air. A camera photographs the leaves. A Raspberry Pi (a credit-card-sized computer) collects everything and sends it to a server. The farmer then sees it all on a phone app, and gets an alert when something goes wrong.

PieceSimple explanation
Mosquitto (MQTT)A post office for small messages. The Pi drops a letter ("pH = 6.1"), and whoever subscribed receives it.
Node-REDA sorting desk. It opens every letter, throws away the malformed ones (and reports them), and forwards the good ones.
APIThe brain. It stores readings, decides when to raise an alert, and checks whether a pump command is safe.
IAMThe front door with a guard: sign-up, login, and who is allowed to do what (farmer or administrator).
PWAA web page that installs on a phone like an app. There is one for farmers and one for administrators.

3a. How an alert is born

Six kinds of alerts exist: a value out of range, a sensor that went silent, the Pi offline, a pump failure, a broken message, and a leaf that looks sick on camera.

3c. Nothing is lost when the network drops

The Pi writes every reading into a small notebook (a database file on its memory card) before sending it. A line is crossed out only once the server confirms it arrived. If the Wi-Fi drops, the notebook simply fills up, and it empties when the connection returns. Late readings are labelled "buffered", so the app shows them in the history and never as the current value.

4. Today: the real hardware joins

4a. Connecting the Raspberry Pi

  • Plugging the cable straight into the laptop showed "Réseau non identifié". That's normal: with nobody handing out addresses, the Pi got no usable address. Fix: connect it to the Flybox router, which gave it an address (Wi-Fi 192.168.1.129).
  • The camera wasn't detected at first. After re-seating the ribbon cable, it was recognised as a Camera Module v2.1 (Sony IMX219 sensor, 8 megapixels).
  • Docker (which runs the servers) was started on the laptop, and the Pi was registered as basil-pi-01.
  • Result: the Pi connected and sent its first 60 readings and its first camera check within a minute. The sensors are still simulated (the real probes haven't arrived), and the data is honestly marked "not calibrated".

4b. Teaching an AI to spot sick leaves

We downloaded a public set of 58 basil photos where people drew a box around each leaf and named its condition. We trained YOLO26n, a small, fast "find the objects" model, on the laptop's graphics card. It took about 2 minutes.

6. Small glossary

CommitOne saved step of work, with a message describing it.
Pull request / mergeA proposal of commits, reviewed by a teammate, then added to the main version.
Simulated sensorA program that invents realistic values, so we can build everything before the real sensor arrives.
CalibratedA sensor adjusted against a known reference (for example a pH 7 liquid), so its values can be trusted.
DockerRuns each server in its own sealed box, so the whole system starts with one command on any computer.
Training / test photosThe AI learns from the training photos; the test photos are kept hidden until the end, to measure it honestly.
AugmentationMaking extra training photos by rotating, re-lighting or blurring the existing ones.
Review requiredWhat the app shows when the AI is unsure. It never presents a guess as a diagnosis.
